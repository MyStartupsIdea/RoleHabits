# RoleHabits

RoleHabits — это веб-приложение для формирования, отслеживания и поддержания профессиональных ежедневных привычек. Интерфейс полностью на русском языке.

## Возможности

- **Онбординг-визард** (обязательный при первом посещении): выбор профессии, уровня опыта и дневной цели с предпросмотром предустановленных привычек.
- **Дашборд**: шапка с профилем, уровнем, прогресс-баром XP и счётчиком серии дней (streak).
- **Геймификация**: +50 XP за каждую выполненную привычку, повышение уровня (Junior → Middle → Senior → Lead).
- **Чек-лист привычек**: интерактивные карточки с чекбоксами, временем, категориями и значками сложности.
- **Прогресс дня**: полоса от 0% до 100% с конфетти-эффектом при достижении 100%.
- **Добавление/редактирование/удаление привычек** с подтверждением удаления.
- **Тепловая карта недели**: визуальная активность за последние 7 дней.
- **6 профессий** с 4–5 предустановленными привычками для каждой.
- **Тёмная тема** с акцентами Indigo/Violet, плавные анимации (Framer Motion).

## Технологии

- React + Vite + TypeScript
- Tailwind CSS
- Lucide Icons
- Framer Motion
- canvas-confetti

## Запуск

```bash
npm install
npm run dev
```

Данные сохраняются в localStorage браузера.
